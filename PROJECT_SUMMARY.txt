================================================================================
                          DEPLOYMENT OPTIONS
================================================================================

OPTION 1: VERCEL (RECOMMENDED)
-------------------------------
1. Push to GitHub:
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/cumberland-tech.git
   git push -u origin main

2. Go to vercel.com
3. Import your GitHub repository
4. Click "Deploy"
5. ✅ Site is live!

OPTION 2: VERCEL CLI
--------------------
npm install -g vercel
vercel login
vercel --prod

OPTION 3: NETLIFY
-----------------
1. Run: npm run build
2. Drag dist/ folder to netlify.com
3. ✅ Site is live!

OPTION 4: GITHUB PAGES
----------------------
See DEPLOYMENT.md for detailed instructions

================================================================================
                           TROUBLESHOOTING
================================================================================

ISSUE: Build fails
SOLUTION: Delete node_modules and package-lock.json, then run npm install

ISSUE: Images not loading
SOLUTION: Check image URLs in src/App.tsx are correct

ISSUE: WhatsApp links not working
SOLUTION: Verify phone number format (no spaces, include country code)

ISSUE: Styles not loading
SOLUTION: Clear browser cache, check Tailwind is imported in src/index.css

ISSUE: 404 on page refresh (after deployment)
SOLUTION: Ensure vercel.json has rewrites configured (already included)
